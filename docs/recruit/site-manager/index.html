Job Summary

職務概要

データセンターを中心とした通信設備・ICT工事の現場で、日々の施工活動（サーバー設置、ラック実装、光・メタル配線、成端、試験など）を監督する現場監督（Site Manager）を2名採用します。

作業員・協力会社をまとめ、安全（TBM）・品質・工程・資機材を管理しながら、プロジェクトマネージャー・エンジニア・安全担当・客先と連携して現場を前に進める、プロジェクトの最前線を担うポジションです。

当社に入社する理由

  • データセンターという成長領域の最前線で、需要が拡大し続けるDC構築プロジェクトの現場経験を積めます。
  • 2026年に始動した日本法人の現場チームの中核として、立ち上げ期から現場のやり方づくりに関われます。
  • 日本・シンガポール・マレーシア・タイの4カ国グループ。海外チームや外資系客先と接する機会があり、英語を活かせる環境です。
  • 現場監督から、施工管理・プロジェクトマネージャーへのキャリアパス。会社の成長に応じた昇給・昇進の機会があります。

現場を安全に、きれいに、予定どおりに動かすことに誇りを持てる方を求めています。

Responsibilities

業務内容

現場施工の監督

  • サーバー設置、ラック＆スタック、光・メタル配線、ケーブル敷設、成端、パッチング、試験など日々の現場作業の監督
  • 承認図面、施工要領書（Method Statement）、SOP、客先仕様に沿った施工の徹底
  • ケーブルルーティング・整線・ラベリング・現場の整理整頓（ハウスキーピング）の管理

安全・人員・協力会社管理

  • 毎日のツールボックスミーティング（TBM）の実施と、作業内容・安全要求事項の周知
  • 作業員の出勤・生産性・作業進捗の管理
  • 協力会社の作業監理と、プロジェクト要求事項への準拠確認

品質・検査・引き渡し

  • 完了作業の検査と、提出・引き渡し前の品質基準の確認
  • 試験・検査・パンチリスト是正・プロジェクト引き渡しの支援

報告・調整

  • 日次の進捗報告・人員報告・作業アップデートの作成・提出
  • 資機材・工具の管理と、不足の事前報告
  • プロジェクトマネージャー、エンジニア、安全担当、協力会社、客先担当者との調整
  • 現場の問題・遅延・技術的課題の早期発見とPM・エンジニアへのエスカレーション
  • その他、マネジメントが指示する現場関連業務

REQUIREMENTS必須条件

  • 現場監督・職長・リーダーなどとして、作業員や協力会社をまとめた経験
  • 図面・施工要領書・SOPを理解し、現場の施工に落とし込める方
  • 日報・進捗報告書を作成できる基本的なPCスキル
  • 日本語での業務コミュニケーション（現場・客先対応が可能なレベル）

PREFERRED歓迎条件

  • データセンター・通信設備・電気設備などの現場実務経験3年以上（配線・ラック実装・成端・試験など）
  • データセンター構築プロジェクトの経験
  • 光ファイバー融着・測定・試験、LAN・MPO・LC・SCなどの施工経験
  • 職長・安全衛生責任者教育の修了
  • 電気通信工事施工管理技士・電気工事施工管理技士・電気工事士などの資格
  • 英語でのコミュニケーションが可能な方（海外チーム・外資系客先との連携）
