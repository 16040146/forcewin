Job Summary

職務概要

Forcewin-ICT株式会社は、一般建設業許可の「電気通信工事業」を取得し、データセンターやICT関連工事を適法に受注・施工できる体制を構築します。その中核として、1級電気通信工事施工管理技士の資格を持つ技術者を1〜2名採用します。

主な業務は、LAN・光ファイバー・データセンター関連工事の施工管理、品質・安全管理、協力会社との調整、建設業許可申請への協力です。採用後は、当社の営業所技術者候補として登録を進める予定です。

当社は将来的に特定建設業許可（電気通信工事業）の取得を目指しています。監理技術者となり得る1級電気通信工事施工管理技士は、その計画の中核を担う存在です。

当社に入社する理由

  • 2026年に始動した日本法人の、技術部門の立ち上げそのものに関われます。建設業許可取得という会社の根幹を支える、代えの利かないポジションです。
  • データセンターという成長領域で、日本・シンガポール・マレーシア・タイの4カ国グループの案件に携われます。
  • 営業所技術者から、現場代理人・主任技術者、特定建設業許可取得後は監理技術者や技術・安全部門の責任者へ——組織の成長に応じたキャリアパスがあります。
  • 資格・経験・前職年収を考慮した柔軟な給与設定で迎えます。

資格をお持ちなだけでなく、現場にも行政手続きにも柔軟に対応し、新会社の立ち上げに積極的に参加していただける方を求めています。

Responsibilities

業務内容

施工管理

  • データセンターにおける施工管理
  • LAN・光ファイバー・ネットワーク工事の施工管理
  • 工事計画、工程、安全、品質の管理
  • 電気通信工事に関する技術管理

調整・技術打ち合わせ

  • 現場担当者・協力会社との調整
  • 協力会社との技術的な打ち合わせ

技術ドキュメント

  • 見積書、施工計画書、作業手順書などの作成

建設業許可・営業所技術者業務

  • 建設業許可（電気通信工事業）申請に必要な資格証明資料の提出
  • 許可取得後の営業所技術者等としての業務
  • 将来的な現場代理人、主任技術者業務

REQUIREMENTS必須条件

  • 1級電気通信工事施工管理技士の資格を有すること（電気通信工事業の「営業所技術者等」の要件を満たす方）

  • 電気通信工事、LAN配線、光ファイバー工事などの実務経験
  • 基本的なPC操作ができること
